# 🏥 MediCare AI Platform

A **multi-agent AI healthcare system** that enables medical question answering, document retrieval, summarization, and intelligent advisory using LLMs and vector search.

---

## 🚀 Live Demo

👉 http://3.82.48.175/

---

## 🧠 Features

* 🔹 **Conversational RAG Agent** (context-aware medical chatbot)
* 🔹 **Document QA Agent** (stateless retrieval API)
* 🔹 **Medical Summarization Agent**
* 🔹 **Confidence & Validation Agent**
* 🔹 **Symptom-based Advisory Agent**
* 🔹 **Real-time Metrics & Latency Tracking**

---

## 🧩 Architecture

* LLM: **LLaMA 3 (via Groq)**
* Retrieval: **Pinecone Vector DB**
* Framework: **LangChain**
* Backend: **Flask**
* Deployment: **Docker + AWS EC2**

## 🛠️ Local Setup

```bash
git clone https://github.com/Eva13-sys/MediCare
cd MediCare

conda create -n medicare python=3.10 -y
conda activate medicare

pip install -r requirements.txt
```

### Create `.env`

```
PINECONE_API_KEY=your_key
GROQ_API_KEY=your_key
PINECONE_HOST=your_host
```

### Index Data

```
python store_index.py
```

### Run App

```
python app.py
```

---

## 🐳 Docker Run

```bash
docker build -t medicare .
docker run -d -p 80:8080 --env-file .env medicare
```
